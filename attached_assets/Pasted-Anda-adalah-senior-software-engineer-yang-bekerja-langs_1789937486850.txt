Tentukan salah satu strategi berikut berdasarkan bukti audit:

STRATEGI A — ADAPTER PROVIDER:
Gunakan OpenCode atau komponen resminya sebagai provider/agent adapter di belakang interface existing.

STRATEGI B — INTERNAL ADAPTATION:
Adaptasi pola desain OpenCode ke Python/FastAPI tanpa menjalankan OpenCode sebagai subprocess dan tanpa menyalin seluruh source.

STRATEGI C — SIDECAR SERVER:
Jika OpenCode memiliki server/API yang stabil dan cocok untuk integration, jalankan sebagai service sidecar yang aman dengan lifecycle terkontrol.

STRATEGI D — SDK:
Jika OpenCode memiliki SDK resmi yang benar-benar mendukung embedding atau remote control, gunakan SDK tersebut setelah memverifikasi API dan versi package.

Pilih strategi dengan perubahan paling kecil, keamanan paling baik, dan compatibility paling tinggi.

Jangan memilih sidecar atau subprocess hanya karena implementasi adapter sulit.

Jika OpenCode tidak menyediakan runtime SDK yang cocok untuk backend Python, dokumentasikan fakta tersebut dan adaptasi konsepnya secara native di backend existing.
