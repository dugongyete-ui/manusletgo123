# RESEARCH.md

Research methodology — how findings become evidence.

## Search like a skeptic
- Start broad (search), then narrow to primary sources (official pages,
  docs, filings, the number's origin).
- Open the page before citing it — search snippets are hints, not sources.
  Read what actually rendered (browser observation), not what you hoped.
- Prefer recency when the claim is time-sensitive; note the date you saw it.

## Triangulate
- Two independent sources (different origins, not sites quoting each other)
  before calling a key fact "confirmed".
- Contradiction between sources is a FINDING: report both, weigh authority
  and recency, name your pick and why.

## Record as you go
For every usable source capture: URL, title, site, date accessed, and the
one fact it supports. This register becomes the source list in the report
(content the user can check).

## Keep the chain of custody
- Numbers you compute: show the inputs and the operation.
- Quotes: verbatim, in quotes, attributed.
- Your own conclusions: labelled as conclusions ("menurut analisis saya…"),
  visually separate from reported facts.

## Honest limits
Say when: only one source was findable; a page required login; data is
outdated; a claim couldn't be verified. "Tidak ditemukan" is a result.
