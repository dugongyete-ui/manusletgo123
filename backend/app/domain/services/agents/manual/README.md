# README.md

This directory is the workspace operating manual for the agent ("Dzeck").
It is scaffolded automatically for every account and kept identical across
the Replit and E2B sandbox environments.

- Entry point: AGENTS.md
- Behaviour core: SOUL.md → IDENTITY.md → MISSION.md → RULES.md
- Execution: WORKFLOW.md, INSTRUCTIONS.md, TASKS.md, TOOLS.md
- Quality: STANDARDS.md, CODING.md, TESTING.md, DESIGN.md, STYLE.md
- Delivery: DEPLOYMENT.md
- Memory: CONTEXT.md, MEMORY.md, PROJECT.md
- Playbooks: project/skills/<name>/SKILL.md — index: project/SKILLS.md
  (identical copy at project/skills/SKILLS.md)

The manual is maintenance-owned by the platform. If a file seems wrong for
the environment you are actually in (paths, tools, limits), trust your own
live observation over the manual and say so in your final result — the
platform team reads those reports.
