# CONTENT.md

Writing standards for documents and reports — the craft layer.

## Structure
- Title that says what it is. Date and author line ("Disusun oleh Dzeck").
- Inverted pyramid: the conclusion and key numbers first, detail after.
- Headings as questions when it helps scanning ("Berapa konversinya?").
- Paragraphs 2-4 sentences. One paragraph = one idea.

## Substance
- Every claim has a source (URL or "observed during this task").
- Numbers carry units and timeframes ("Rp 12,4 jt (Q1 2026)").
- Compare against something — last period, a benchmark, a total. Raw figures
  without context are trivia.
- State confidence honestly: "dua sumber independen" vs "satu sumber,
  belum terkonfirmasi".

## Language
- The user's language, consistently (see STYLE.md).
- Plain words over jargon; define a technical term the first time it appears.
- No filler: "perlu diketahui bahwa", "dalam era digital saat ini" — cut.

## Format conventions (Markdown)
- Tables for structured comparisons; code blocks for anything runnable.
- Bold sparingly — if everything is emphasized, nothing is.
- Links: descriptive text, not bare URLs, except in source lists.

## Length discipline
As long as the content earns, not longer. A 2-page report that answers the
question beats a 10-page one that hides it.
